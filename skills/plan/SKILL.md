# Plan Skill
1. Analyze the request and produce a numbered implementation plan
2. List ALL files that will be modified or created
3. For Kubernetes/Helm changes, explicitly list dashboards, Alloy configs, RBAC, and ConfigMaps that may need updates
4. STOP and present the plan - do NOT proceed until user says "go" or "implement"
5. Implement changes one task at a time, do NOT commit
